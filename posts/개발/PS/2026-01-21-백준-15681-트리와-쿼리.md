이 문제는 가중치가 없는 트리(루트 포함)가 주어질 때, 정점 U를 루트로 하는 서브 트리(부분 트리)에 속한 정점의 수를 구하는 문제이다. 

가장 간단하게 생각해 볼 수 있는 풀이 방법은 recursive DFS를 이용하는 것이다. `int dfs(node)` 함수를 구현하여 node를 시작점으로 dfs를 수행하며 찾은 모든 노드의 개수를 반환하도록 한다. 또한 결과를 `dp[node]`에 저장하여 추후 쿼리 시 $O(1)$로 답을 찾을 수 있도록 한다. 이 구현 방법은 재귀함수의 특징을 이용해 리프 노드부터 루트 노드까지 순서대로 노드 개수를 계산하여 더하는 것으로 구현이 간단한 장점이 있다. 반면 트리 높이가 너무 높아서 재귀 함수가 스택 프레임에 너무 많이 쌓일 경우 스택 오버플로우가 발생할 수 있다는 점은 고려해야 한다. 이 문제의 경우에는 recursive DFS로도 통과할 수 있었다. 

만약 스택 오버플로우나 코드 성능을 우려한다면 iterative DFS로도 풀 수 있다. 먼저 DFS를 통해 루트 노드부터 시작하는 트리의 순회 순서와 각 노드별 부모 노드를 기록한다. 그런 다음, 기록된 트리 순회 순서의 역순으로 돌면서 자신의 부모 노드의 dp 원소에 자신의 dp 원소를 더해준다. 이 과정을 완료하면 dp 배열에 최종적인 서브 트리의 원소 개수가 구해진다.

두 방식 모두 dp의 정의와 점화식 자체는 동일하다. `dp[i]`를 자기 자신을 루트로 하는 서브 트리의 정점 개수로 정의하면 점화식은 아래와 같다.

$$

dp[i] = 1 + \sum_{v \ \in \ \text{children}[i]} dp[v]
$$

여기서 $\text{children}[i]$ 는 루트 R을 기준으로 부모를 제외한 인접 정점들(즉, i의 자식들)을 의미한다.
또한 1을 더하는 이유는 자기 자신을 정점 개수로 포함해야 하기 때문이다. 

[🔗 문제 링크](https://www.acmicpc.net/problem/15681)

## 코드

### 재귀로 풀 경우

먼저 정점의 개수 N, 루트 노드의 번호 R, 질의의 개수 Q를 입력받는다. 

```java
public static void main(String[] args) throws IOException {
    StringTokenizer st = new StringTokenizer(br.readLine());

    int N, R, Q;
    N = Integer.parseInt(st.nextToken());
    R = Integer.parseInt(st.nextToken());
    Q = Integer.parseInt(st.nextToken());
```

다음으로 다이나믹 프로그래밍을 위한 `dp`배열과 노드 방문 체크를 위한 `visited` 배열을 선언한다. 또한 트리를 저장하기 위해 인접 배열 형태로 선언하고 `ArrayList`로 초기화해 준다.
```java
    dp = new int[N+1];
    visited = new boolean[N+1];

    @SuppressWarnings("unchecked")
    List<Integer>[] tree = new List[N+1];

    for (int i = 0; i <= N; i++) 
        tree[i] = new ArrayList<>();
```

다음으로 트리를 입력받는다.
```java
    for (int i = 0; i < N-1; i++) {
        st = new StringTokenizer(br.readLine());
        int a = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());

        tree[a].add(b);
        tree[b].add(a);
    }
```

이제 이 코드에서 핵심 로직인 dfs를 수행한다. 앞서 설명했듯 dfs 함수는 트리를 재귀적으로 순회하며 리프 노드부터 루트 노드까지의 노드 개수를 구하게 된다. 또한 각 노드마다, 그 노드를 루트로 하였을 때 서브 트리가 가진 정점의 개수를 dp에 저장한다.


```java
    dfs(R, tree);
    // ...


public static int dfs(int node, final List<Integer>[] tree) {
    visited[node] = true;
    
    int tot = 1;
    for (int adj : tree[node]) {
        if (visited[adj]) continue;
        tot += dfs(adj, tree);
    }
    dp[node] = tot;
    return tot;
}


```

dfs를 통한 트리 순회를 완료하면 쿼리를 입력받아 dp배열에 있는 값을 가져온 뒤 출력한다. 답변을 모두 출력하면 프로그램을 종료한다.

```java
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < Q; i++) {
        int q = Integer.parseInt(br.readLine());
        sb.append(dp[q]).append("\n");
    }
    System.out.print(sb);
}
```

### 반복문으로 풀 경우

입력 코드는 이전과 비슷하므로 달라진 부분 위주로 살펴보자.

기존에 선언했던 변수 이외에 `parent`와 `traverse` 배열을 추가로 선언하였다. `parent` 배열에는 어떤 노드의 부모 노드가 무엇인지 저장해둔다. traverse에는 DFS의 방문 순서를 저장해둔다.

```java
    int[] parent = new int[N+1];
    int[] traverse = new int[N];
    int tIdx = 0;
```

DFS를 수행하기 위해 dq를 선언한다. 루트 노드인 R을 삽입하고 방문처리도 해 준다. 이후 반복문을 돌며 DFS를 수행한다.

스택에서 노드를 꺼낸 뒤 `traverse[tIdx++] = node`를 수행한다. 즉 방문 순서를 traverse에 저장한다. 다음으로 인접 노드들에 대해 `parent[adj] = node`로 인접 노드의 부모를 지정해준다. 다음으로 방문 처리 후 스택에 넣는다. 

```java
    Deque<Integer> dq = new ArrayDeque<>();
    dq.addFirst(R);
    visited[R] = true;

    while (!dq.isEmpty()) {
        int node = dq.pollFirst();
        traverse[tIdx++] = node;
        for (int adj : tree[node]) {
            if (visited[adj]) continue;
            parent[adj] = node;
            visited[adj] = true;
            dq.addFirst(adj);
        }
    }
```

다음으로 dp 배열을 점화식을 이용해 계산해준다. 먼저 모든 dp 배열의 원소를 1로 채워준다. 왜냐하면 모든 서브 트리의 노드 개수는 최소 1개이기 때문이다. 

다음으로 N-1부터 1까지 반복문을 돌며 점화식을 계산해준다.
`traverse`에는 부모가 자식보다 먼저 들어가므로(preorder traverse), 이를 역순으로 처리하면 항상 자식의 dp가 먼저 확정되고 그 값을 부모에 누적할 수 있다. 

따라서 DFS에서 순회한 순서의 역순으로 노드를 골라 그 노드를 루트로 하는 서브 트리의 노드 개수를(`=dp[traverse[i]]`) 선택한 노드의 부모 노드를 루트로 하는 서브 트리의 노드 개수에 더해준다(`=dp[parent[traverse[i]]]`)

```java
    Arrays.fill(dp, 1);

    for (int i = N-1; i > 0; i--) {
        dp[parent[traverse[i]]] += (dp[traverse[i]]);
    }
```

이후 쿼리를 입력받아 정답을 출력하는 코드는 이전과 같아 생략하였다.

## 전체 코드

### 재귀로 풀 경우
```java
import java.util.*;
import java.io.*;

class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static int[] dp;
    static boolean[] visited;
    public static void main(String[] args) throws IOException {
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N, R, Q;
        N = Integer.parseInt(st.nextToken());
        R = Integer.parseInt(st.nextToken());
        Q = Integer.parseInt(st.nextToken());

        dp = new int[N+1];
        visited = new boolean[N+1];

        @SuppressWarnings("unchecked")
        List<Integer>[] tree = new List[N+1];

        for (int i = 0; i <= N; i++) 
            tree[i] = new ArrayList<>();


        for (int i = 0; i < N-1; i++) {
            st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());

            tree[a].add(b);
            tree[b].add(a);
        }

        dfs(R, tree);

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < Q; i++) {

        }
        System.out.print(sb);
    }

    public static int dfs(int node, final List<Integer>[] tree) {
        visited[node] = true;
        
        int tot = 1;
        for (int adj : tree[node]) {
            if (visited[adj]) continue;
            tot += dfs(adj, tree);
        }
        dp[node] = tot;
        return tot;
    }
}
```

### 반복문으로 풀 경우
```java
import java.util.*;
import java.io.*;

class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static int[] dp;
    static boolean[] visited;
    public static void main(String[] args) throws IOException {
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N, R, Q;
        N = Integer.parseInt(st.nextToken());
        R = Integer.parseInt(st.nextToken());
        Q = Integer.parseInt(st.nextToken());

        dp = new int[N+1];
        visited = new boolean[N+1];

        @SuppressWarnings("unchecked")
        List<Integer>[] tree = new List[N+1];

        for (int i = 0; i <= N; i++)  
            tree[i] = new ArrayList<>();


        for (int i = 0; i < N-1; i++) {
            st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());

            tree[a].add(b);
            tree[b].add(a);
        }

        int[] parent = new int[N+1];
        int[] traverse = new int[N];
        int tIdx = 0;

        Deque<Integer> dq = new ArrayDeque<>();
        dq.addFirst(R);
        visited[R] = true;

        while (!dq.isEmpty()) {
            int node = dq.pollFirst();
            traverse[tIdx++] = node;
            for (int adj : tree[node]) {
                if (visited[adj]) continue;
                parent[adj] = node;
                visited[adj] = true;
                dq.addFirst(adj);
            }
        }

        Arrays.fill(dp, 1);

        for (int i = N-1; i > 0; i--) {
            dp[parent[traverse[i]]] += (dp[traverse[i]]);
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < Q; i++) {
            int q = Integer.parseInt(br.readLine());
            sb.append(dp[q]).append("\n");
        }
        System.out.print(sb);
    }
}
```

## 시간복잡도

재귀의 경우 dfs를 통해 트리를 순회하면서 동시에 dp에 값을 계산해 저장한 뒤, 질의에 대한 답을 dp에서 꺼내 출력한다. 노드 개수가 N이므로 dfs의 시간복잡도는 $O(N)$이고, 쿼리 개수만큼 답변을 꺼내오는 시간복잡도는 $O(Q)$ 이다. 따라서 최종 시간복잡도는 $O(N+Q)$ 이다.

반복문의 경우 dfs에 $O(N)$, 점화식을 통한 dp 계산에 $O(N)$, 쿼리에 따른 답변에 $O(Q)$의 시간이 걸리므로 $O(2N+Q) \approx O(N+Q)$ 이다.

최악의 경우에도 $2\times 10^5 \lt 1\text{억}$ 이므로 1초 내에 통과할 수 있다.
